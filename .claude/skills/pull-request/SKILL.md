Create a PR to the repo's default branch using `gh pr create`.

Before writing the PR body, run the **humanizer** skill on your draft.

PR body format:

```
## Summary

**tldr: <one-line plain-english summary>**

<1-3 sentences of context — why this change exists, what it fixes or enables.>

## Changes

- <concrete change>
- <concrete change>
```

Keep it short. Write like a human engineer talking to a teammate. No emojis, no fluff, no "Generated by AI" footers.
